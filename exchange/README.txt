MCP-CLEAN exchange

Purpose:
- служебный обмен между разрешёнными проектами
- структура только для обмена и временных файлов
- код проектов не изменяется

Folders:
- incoming: входящие файлы и запросы
- outgoing: исходящие ответы и результаты
- artifacts: подготовленные артефакты
- temp: временные файлы
- projects: отдельные рабочие маркеры по проектам

See also:
- index.json for the current exchange inventory
